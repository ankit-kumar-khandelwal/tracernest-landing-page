Package Overview

Complete TracerNest Telemetry Suite

Zero external ports, zero runtime dependencies, and authenticated AES-256-GCM encryption across modern backends.

tracernest-logger (Node.js)

npm install tracernest-logger

Zero-port flight recorder and encrypted log vault for Node.js (Express, Koa, Fastify, vanilla HTTP). Features native V8 request sampling, local authenticated AES-256-GCM storage, and zero-downtime SQLite to MySQL auto-migration.

tracernest-laravel (Laravel 13)

PHP Monolog • Middleware

Native PHP Monolog handler and HTTP middleware bridge for Laravel 13, 12, and 11. Connects route lifecycles, database query durations, and exception stack traces directly into TracerNest's unified encrypted vault without daemon ports.
