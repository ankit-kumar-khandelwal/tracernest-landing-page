Code of Quality

Four-Step Contribution Workflow

Follow our streamlined development guidelines to ensure your pull request is reviewed and merged swiftly.

01 PHASE 1

Fork & Clone Repository

Fork the repository on GitHub and clone your local copy:

git clone https://github.com/ankit-kumar-khandelwal/tracernest-logger.git
cd tracernest-logger
02 PHASE 2

Zero Dependency Policy

Strict Rule: TracerNest maintains an empty dependencies: {} policy. PRs adding runtime packages will be closed. Rely exclusively on native Node.js standard libraries.

03 PHASE 3

Run Comprehensive Test Suite

Ensure that all 33+ unit and integration tests pass cleanly before submitting code:

npm test
npm run build
04 PHASE 4

Submit Your Pull Request

Create a descriptive feature branch (e.g. feat/postgres-adapter), commit your changes using conventional commits, and open a PR against main on GitHub.
