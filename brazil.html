Zero-port telemetry flight recorder and AES-256-GCM encrypted log vault. Hooks directly into Express, Koa, Fastify, and native HTTP pipelines on your existing port. Zero runtime dependencies (dependencies: {}).

  • Zero extra ports required (mounts on existing port e.g. /tracernest).

tracernest-laravel (Laravel 13)

PHP Monolog Bridge

Native PHP Monolog handler and HTTP middleware bridge for Laravel 13, 12, and 11 applications. Unified request correlation IDs spanning frontend, Node.js, and Laravel backends.

  • Full Monolog integration capturing controller execution and exception traces.
  • Database query durations and memory tracking without queue daemons.
  • Stores encrypted logs in unified SQLite or MySQL database.
