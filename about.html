Native Ecosystem

Complete Package Architecture & Runtimes

TracerNest offers two production-grade packages built to deliver end-to-end telemetry across modern microservices, full-stack Node.js architectures, and enterprise Laravel applications.

tracernest-logger

Node.js Package • v1.9.0

The core zero-dependency, zero-port telemetry flight recorder and encrypted log vault for Node.js backends. Hooks natively into your HTTP pipeline without exposing new ports or adding third-party security vulnerabilities.

  • Zero Extra Ports: Attaches to existing Express, Koa, Fastify, and native HTTP request pipelines, serving the embedded dashboard at /tracernest on your existing application port.
  • Zero Runtime Dependencies: dependencies: {} in package.json. Relies strictly on native V8 internals, standard node:crypto, node:http, and node:sqlite libraries.
  • AES-256-GCM Vault: All log payloads, headers, stack traces, and metadata are encrypted with authenticated 128-bit integrity tags before touching disk or database storage.
  • SQLite to MySQL Auto-Migration: Starts zero-config with SQLite WAL. When enterprise concurrency is needed, switches to MySQL with automated DDL migration and zero data loss.
  • Embedded Real-Time Dashboard: Built-in live streaming, instant regex search, level filters, latency breakdown, memory telemetry, and payload inspector.

tracernest-laravel

Laravel 13 • PHP Bridge

Official PHP middleware and Monolog handler bridge connecting Laravel 13, 12, and 11 applications directly to the TracerNest telemetry engine without opening daemon ports or installing heavy background agents.

  • Seamless Monolog Integration: Automatically intercepts standard Laravel Log::info(), Log::error(), and uncaught exceptions with full stack traces and contextual bindings.
  • Request Lifecycle Tracking: Records route execution duration, database query counts, memory consumption, HTTP response codes, and authenticated user IDs.
  • Unified Log Vault Correlation: Stores PHP telemetry in the same AES-256-GCM encrypted database (SQLite or MySQL) alongside Node.js services for unified full-stack observability.
  • Zero-Downtime Daemon-Free Architecture: Operates completely within PHP-FPM or Octane request lifecycles without requiring external Redis or RabbitMQ queues.

Why We Built TracerNest

Our Core Engineering Principles

We believe modern observability should be transparent, zero-cost, memory-safe, and independent of external SaaS telemetry platforms.

Freedom from SaaS Taxes

Traditional logging platforms charge thousands of dollars per month based on uncompressed data volume and cloud egress. TracerNest runs directly inside your infrastructure, consuming zero egress and eliminating ongoing SaaS subscriptions.

Supply-Chain Resilience

Node.js logging libraries commonly pull dozens of transitive npm dependencies that introduce critical CVEs and supply-chain exploits. TracerNest uses zero third-party dependencies—relying solely on native Node.js core libraries.

Zero-Port Defense

Opening new daemon ports (like 8080 or 9200) expands your firewall attack surface and complicates container deployments. TracerNest attaches into your existing HTTP request router, serving telemetry on your current application port.
